# 蕾缪安：接入与维护

知识版本 0.3.2、人格 0.4.1、表达参考 0.3.6。已完成接入实现与原生 AstrBot 隔离联调；2026-09-24 在 njuse 启用私聊，现覆盖全部 QQ 私聊与群聊。

## 文件放在哪里

| 目录 | 内容 |
| --- | --- |
| `knowledge/lemuen/` | 唯一的资料源、人格、表达参考、出处及校对说明 |
| `plugins/astrbot_plugin_lemuen/` | 小插件：调用原生检索、附入完整语音、标记说话者 |
| `scripts/lemuen.py` | `check`、`build`、`smoke` 三个维护命令 |
| `tests/fixtures/lemuen.json` | 少量事实与聊天回归用例 |

| `runtime/lemuen/latest-smoke.*` | 最近一次实际联调结果，后续运行覆盖 |

多轮评测报告、旧模型比较脚本、重复主题 Markdown 和生成文档不再随仓库保留。出处与人物资料没有删减。

## 运行方式

人格使用 AstrBot 原生人格管理，69 个原作块和 1 个 EP 歌词块使用原生知识库管理。插件只在“已启用 + 会话匹配允许规则 + 当前选择蕾缪安人格”同时成立时运行。规则支持通配符，`napcat:FriendMessage:*` 覆盖当前及未来所有 QQ 私聊；`napcat:GroupMessage:*` 覆盖全部群聊。

人格 0.4.1 保留从容、亲切、有主见和对生活的兴致，明确先理解当前话题、保持指代一致、能修正自己说错的话。群聊通常只接当前消息及引用对应的话题，不顺带补答背景旁支；明确追问旧事或一次问多件事时，按本轮请求回答。幽默随具体意思自然出现；段落按内容拆分，不为条数补话。修改可在 WebUI「人格」→「蕾缪安」查看。

每轮系统提示词固定加入 `knowledge/lemuen/voice-lines.json` 的 38 条游戏语音全文，正文共 1,522 字，保留场景标题。语音随蕾缪安插件 0.4.0 打包，用于已允许的私聊、群聊和主动私聊；即使检索未命中或超时也保留。来源为已核对的游戏台词资源 V，构建时可用原文缓存逐条校验。战斗、生日等原场景保留各自语境，信赖标题不引入养成过程。

当前问题涉及人物别名或原作话题时，从原生知识库取最多两条资料；未命中主题词或别名时跳过角色检索，话题范围由 `render.py` 的原作主题词与现有 `aliases.json` 维护，只用当前问题（含明确引用）检索，不再自动拼接同一成员的旧发言。资料作为当轮临时参考，保存聊天历史时移除；系统提示词保留原生人格与完整语音。`voice-guide.json` 保留为人工维护依据，手写样例与表达规则不再逐轮注入，也不随插件打包。检索失败时继续使用人格和语音。

说话者标记跟随用户消息保存。Rolebot 补充最近 6 条或 3 分钟群消息的并集，包含未触发回复的群消息及对应图片观察；这层窗口与 AstrBot 更早的会话历史并存。背景图片的原地址与描述留在有界内存窗口中，描述仅用于当轮。按好友隔离的长期记忆见 [插件配置](plugins.md)；不设养成机制。

推荐不在该会话的原生自动知识库列表重复选择“蕾缪安”，由插件调用原生检索接口；如果 AstrBot 已注入同一知识库，插件复用已有结果。此时检索问句按 AstrBot 原生规则处理。时间线与知情字段随完整块提供，仍不是结构化的检索过滤条件。

## EP 歌词

《Sanctuary Inside》按用户提供的 52 行英文全文收录在 `entries.json` 的 L108，来源 UEP1。包括重复副歌，整首作为一个检索块，按歌名、EP 或歌词片段召回。它属于歌曲的抒情表达，不据其中意象编造角色经历或与用户的关系。未做外部原文或音频校对。

前端进入「知识库」→「蕾缪安」→「蕾缪安-角色EP与歌曲.md」可查看完整内容。向已有实例添加时，仅导入该新文档，避免重新导入其他文档造成重复；常驻系统提示词仍由 38 条角色语音组成。

## 检查与打包

```bash
conda activate astrbot-wsl
python scripts/lemuen.py check
python scripts/lemuen.py build
python -m unittest discover -s tests -v
```

这些命令不调用收费 API。构建产物在 `runtime/lemuen/build/`。普通 CI 同样只做离线检查、测试与打包。

原生联调显式调用 API：

```bash
python scripts/lemuen.py smoke --live
# 只检查部分场景
python scripts/lemuen.py smoke --live --cases D07,G01
# 使用某个实际聊天配置中的模型（文件名可在 data/config 查看）
python scripts/lemuen.py smoke --live --profile data/config/abconf-实际配置ID.json
```

默认通过 SSH `njuse` 创建临时 AstrBot 根目录。嵌入配置取自本地 `.env`，聊天提供商取自服务器当前启用配置；密钥不写入结果或仓库。临时实例不加载 QQ 适配器，也不启动 WebUI、systemd 服务或 NapCat。结束后删除临时数据库，保留本地最近一次合成对话结果。真实会话记录不会被读取。

- 前端：<http://127.0.0.1:16185>。修改私聊设置时，在配置页面选择“蕾缪安 · QQ私聊”。

后续新服务器或重新部署时，可按下面步骤配置：

1. 在本地运行 `python scripts/lemuen.py build`。
2. 经 SSH 隧道打开 AstrBot WebUI：<http://127.0.0.1:16185>。
3. 添加 OpenAI 兼容嵌入提供商：Base URL `https://dashscope.aliyuncs.com/compatible-mode/v1`，模型 `qwen3.7-text-embedding`，维度 1024，维度发送模式 `always`。Key 从自己的 `.env` 配置到后台，不写入人格文件。
4. 创建名为“蕾缪安”的知识库，选择该嵌入提供商。稠密和稀疏候选各 20，最终返回 2，重排序暂不配置。通过预分块 JSON 导入生成的 `astrbot-import.json`；每条资料作为完整块。
5. 创建名为“蕾缪安”的人格，填入生成的 `persona.md`。初期不配置开场共同往事、工具和技能。
6. 从本地 ZIP 安装 `astrbot_plugin_lemuen.zip`。安装默认关闭；在插件配置中填写允许的会话规则，再启用。全部 QQ 私聊使用 `napcat:FriendMessage:*`；空列表不作用于任何会话。
7. 为 QQ 私聊创建独立 AstrBot 配置，默认人格设为“蕾缪安”，并绑定同一规则 `napcat:FriendMessage:*`。群聊随后按 [插件说明](plugins.md#群聊策略与管理) 建立独立配置。初次接入时可为现有私聊新建会话，原会话保留；日常更新人格不需要清空聊天。
8. 将生成的 `private-chat-settings.json` 中设置合并到此私聊配置：启用原生分段回复、仅对模型回复生效、关闭流式回复。它是少量设置项，不能整体替换包含模型等设置的原配置。

停用时先移除私聊/群聊到对应蕾缪安配置的绑定，再关闭插件，并将相关会话换回默认人格。单独关闭插件只停止检索与表达补充，不会撤销原生人格选择。

初次启用备份位于服务器 `runtime/backups/lemuen-private-20260924T074535Z/`；后续更新的最新备份路径记录在 `runtime/lemuen/activation.json`，其中同时保存当前版本和启用范围。备份包含私密配置与数据库，勿提交 Git。

人物资料更新后重新检查、打包、更新对应知识库；修改角色语音需要更新插件 ZIP，修改人格需要更新原生人格。本次部署迁移会同步人格 0.4.1 到 WebUI；从上一版升级时保留检索设置，更早版本仍执行原有五条到两条的默认值迁移。后续重复部署保留后台设置。插件不在启动时自动覆盖后台内容。更换嵌入模型或维度需重建索引。

## 连续消息

普通闲聊由模型组织为 2–4 个短段落，AstrBot 按空行把它们发送成独立 QQ 消息，随机间隔 0.8–1.8 秒；同一段内的句号、问号保留。段数是表达偏好，短确认与告别可只有一条，并非每轮强行凑数。

实现使用 AstrBot 自带的分段回复，无新增第三方插件。分段用于私聊和群聊配置的模型回复，段数随实际内容决定；本群最近 60 秒已成功发送至少 6 条消息时，Rolebot 将后续普通回复完整合并为一条，数量下降后恢复分段；命令回复沿用原样。含代码围栏或超过 600 字符的内容整体发送，减少拆散代码和长文的问题。聊天历史仍保存一次完整回复，后续会话能连贯理解。

设置由 `scripts/lemuen.py` 维护，构建时写入 `runtime/lemuen/build/private-chat-settings.json`。需要改间隔时，也可在该私聊配置的“分段回复”页面调整。人格规定按实际内容分段；框架负责实际发送，插件不另建消息队列。

## 本次验证

2026-10-10：43 项测试、角色资料校验与格式检查通过。上下文图片在 0.4.0 已通过真实视觉 API 验证“甲发图、乙稍后只发文字提问”、观察复用、群隔离和清空；本次保留该流程。

使用实际群聊配置中的 `deepseek-v4-pro` 回放合成 G06 场景，共三轮：只接明确引用的饼干话题、不补答背景中的程序和早八；明确重提程序后自然切换；一次明确问两件事时均作答。联调复用 Rolebot 的群聊规则和背景标头，并通过 AstrBot 原生引用解析，无 QQ 发送。三轮回放符合回复范围预期，但仍有对奖品分配作额外推测的现象，不能据此认为所有对话内容都已准确。只保留 `runtime/lemuen/latest-smoke.*` 的最近一次结果。

原作检索使用别名和主题词判定范围，隐含指代不一定触发检索；模型仍可使用已有会话上下文。需要补充新原作话题时，同步维护资料与主题范围。当前部署通过仓库 CI/CD 发布到 njuse，并在停止 AstrBot 后备份、迁移人格与插件；NapCat 无需重启。
