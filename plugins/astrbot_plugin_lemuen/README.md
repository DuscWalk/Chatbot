# 蕾缪安 AstrBot 插件

配合原生人格与知识库，按每轮话题补充表达参考，并为私聊、群聊保存说话者标记。

在 WebUI 导入名为“蕾缪安”的人格和知识库后，安装本插件 ZIP。在插件配置中启用，并填写允许的会话 UMO；`napcat:FriendMessage:*` 开放全部 QQ 私聊，空列表不生效。对应会话也需要选择“蕾缪安”人格。

知识检索通过 AstrBot 原生接口完成，无额外 Python 依赖。推荐保持该会话的自动知识库列表为空，由插件调用检索；若原生已注入同一个知识库，插件复用结果。详细部署与维护步骤见仓库 docs/lemuen.md。

人物资料与样例由项目维护，表达样例不属于官方台词。兼容范围：AstrBot 4.27.4 至 4.27.x。

## 低频主动私聊

主动聊天默认关闭，需启用并填写精确的私聊 UMO。默认周一、周三、周六北京时间 19–21 点随机一次，最近两小时有对话则跳过；每天最多尝试一次，错过不补发。复用当前人格与原作检索，新增消息会取消待发内容。完整安装与维护说明见仓库 `docs/plugins.md`。
